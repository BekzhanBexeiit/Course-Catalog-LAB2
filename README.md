# Course Catalog

A modern course catalog website built with Next.js for the **Advanced Web Technologies — Lab 2** assignment.

This project presents a responsive learning platform where users can browse available courses, view detailed information for each course, and learn about the lab assignment in a clean and user-friendly interface.

## Overview

The app was designed to showcase a course catalog with:

- a landing page with a strong hero section
- course statistics and category badges
- a responsive course grid
- detailed course pages for each class
- a clear navigation bar with active page highlighting
- modern styling with Tailwind CSS and shadcn/ui components

## Features

- Responsive design for desktop, tablet, and mobile devices
- Course list with cards and key metadata
- Dynamic course detail pages
- Navigation highlighting for the current page
- Professional UI using Tailwind CSS utility classes
- Reusable UI components from shadcn/ui
- Clean and readable layout built for educational content

## Tech Stack

- [Next.js 14](https://nextjs.org/) — React framework with App Router
- [TypeScript](https://www.typescriptlang.org/) — type-safe JavaScript
- [Tailwind CSS](https://tailwindcss.com/) — utility-first styling
- [shadcn/ui](https://ui.shadcn.com/) — prebuilt UI components

## Project Pages

| Route | Description |
|-------|-------------|
| `/` | Home page with hero section, summary statistics, and category badges |
| `/courses` | Full list of courses in a responsive grid |
| `/courses/[id]` | Detailed information for a selected course |
| `/about` | Information about the project and assignment |

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open your browser and visit:

```text
http://localhost:3000
```

## Usage

- Browse the home page to see the available course categories
- Open the course list to view all available classes
- Click on any course to see more information such as credits, instructor, and description
- Navigate through the app using the top menu
